# plan-1539-hero-app-qa Review

## Summary

실제 앱 검사에서 재현한 일곱 문제를 수정했다. 샘플 가져오기·제거 안내의 수명, WAV 10ms 경계·동일 rate 프레임 보존·손상 RIFF 처리, 분석 보류 표시, 샘플 기반 SoundCloud 설명, 네이티브 Select All 메뉴를 개선했다. 직접 비트 작곡을 우선하는 기존 제품 구조는 유지한다.

[완료 계획](../exec_plans/completed/plan-1539-hero-app-qa.md)과 [상세 검증 평가](../quality/plan-1539-assessment.md)에 재현 조건과 검증 범위를 기록했다.

## QA

최종 `npm run release:check`는 2026-09-29 11:14:15 UTC에 exit 0으로 완료했다. 4755.379초 동안 소스·하네스·설정 220파일이 변경되지 않았으며 소스·패키지·로컬 서명·PKG 추출·검사용 설치본의 실제 화면과 네이티브 IO·종료 보호가 통과했다.

검증 빌드와 336항목이 일치하는 앱을 설치하고 deep/strict 서명 검사를 통과했다. 최종 설치본의 개인 도구 검사는 21.201초, 전체 16장르는 977.211초, 제작 프로젝트 14개는 631.450초로 모두 통과했다. 30개 실제 앱 보고서의 실행 경로·번들·프로젝트·WAV 해시를 대조했다. CUA 실제 조작과 최종 소스/설치본 스크린샷 시각 확인을 별도로 수행했다.

완료 문서 이동 후 문서 QA, quality gate, 한국어 주석 검사, diff 검사와 완료 요약 갱신 검사를 수행한다. 종료 코드와 소스 불변성은 ignored `completion-doc-qa-receipt.json`에 보존한다.

## Findings and Review

최종 QA 뒤 구현에 참여하지 않은 코드 리뷰어와 증거·전달 리뷰어가 독립 검토했다. 두 리뷰 모두 조치가 필요한 발견 사항이 없다. 코드 리뷰는 기존 샘플 안내 구현을 메모리에 주입하면 새 성공 안내 회귀가 실패하는 것도 확인했다. 증거 리뷰는 220개 소스, 336개 설치 항목, 30개 실행 보고서와 전달 101파일을 독립 대조했다.

처음 통과한 이전 빌드, 메타데이터 입력 자동화 실패 두 건, 첫 최종 게이트의 synthetic-input 실패를 보존한다. macOS 페이지 입력이 메뉴 accelerator를 거치지 않는다는 격리 재현 후 자동 검사를 native first-responder 메뉴 동작으로 수정했다. 실제 OS Cmd+A는 CUA로 검증했고 자동 메뉴 검사는 `osShortcutTested: false`로 구분한다. 실패 기록을 성공으로 재작성하지 않았다.

최종 파일 감사에서 다운로드 폴더의 `.DS_Store` 두 개를 발견했다. 루트의 해당 운영체제 메타데이터만 경로·해시와 함께 별도 기록하며 모든 선언된 전달 파일·checksum은 정확히 일치한다. 다른 추가 파일이나 전달 파일의 변경·누락은 허용하지 않는다.

## Delivery and Boundaries

샘플링 작곡 11곡과 리믹스 3곡, 총 14곡을 세 로컬 전달 폴더에 저장했다. 업로드용 WAV는 스테레오 44.1 kHz signed PCM24이며, 101개 자료와 98개 checksum을 제공한다. 독립 PCM·패키지 검사는 첫 묶음 163+160개, 추가 묶음 190개, 지정 구간 묶음 316개가 통과했다.

01–05는 샘플을 내장한 완전한 native 프로젝트다. 06–14는 native 반주와 별도 원곡 가공 레이어를 합성한 완성곡이며 프로젝트의 BACKING-ONLY 역할, 샘플 파트·배치표·정확 재합성 도구를 명시했다. 최신 세 곡은 12–15초, 88–89초, 212–216초 전체를 모두 사용한다. 첫 곡은 이 세 샘플 출처만 사용하고, 나머지 두 곡은 각각 두 구간을 추가한다.

음원·원본·개인 메타데이터는 Git에 포함하지 않는다. 사람의 전곡 청취나 SoundCloud 업로드·서비스 변환, 외부 공증·배포 승인을 검증했다고 주장하지 않는다.

## Integration and Evidence

최종 소스는 작업 브랜치에서 커밋하고 QA·리뷰 이후 main에 통합한다. main 및 원격 커밋과 동결된 소스의 일치는 ignored `integration-receipt.json`으로 확인한다. 최종 사용자 앱과 두 이전 설치본을 보존한다.

주 checkout의 ignored `build/desktop/plan-1539-completion-evidence/`에 QA·제작 자료·빌드·보조 스크립트를 보존한다. `evidence-relocation.json`은 원래 경로와 보존 경로를 연결하며, 이전 절대경로를 포함하는 보고서를 재작성하지 않는다. 근거를 보존한 뒤 이 작업의 관리형 worktree만 archive하고 병합한 작업 branch를 삭제한다.
