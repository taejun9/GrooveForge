## 실제 화면과 최종 설치본

격리 저장공간의 production Electron과 최종 설치 앱을 검사했다. CUA로 첫 비트 생성, 재생·정지, 믹서 음소거·해제, 마스터·전달 탭, WAV 내보내기와 네이티브 프로젝트 저장을 조작했다. 10ms 파일의 수정 전 거절·수정 후 가져오기, 샘플 제거와 Undo 복구, 성공 안내 유지·해제를 직접 확인했다.

분석 표시는 작곡 화면의 보류 → 믹스 진입 시 분석 중 → 완료 → 작곡 복귀 시 완료 유지 → 드럼 편집 후 보류 순서로 확인했다. 최종 소스의 작곡·전달 화면과 설치본의 샘플 편집·재시작 화면도 직접 시각 확인했다.

Cmd+A 누락은 네이티브 Edit 메뉴의 Select All 부재와 입력 뒤에 문자열이 추가되는 동작으로 재현했다. 수정 후 CUA의 실제 OS 단축키로 35·63·64자 값을 선택·교체하고 저장·종료했다. 자동 회귀는 메뉴 role과 accelerator를 검사하고 macOS first-responder 메뉴 동작으로 선택·교체·원복을 검증한다. 이 자동 입력은 OS 단축키 검증으로 표시하지 않으며 `osShortcutTested: false`를 기록한다.

## 14곡 전달과 재현성

총 샘플링 작곡 11곡과 리믹스 3곡을 사용자 요청의 로컬 전달 폴더에 저장했다. 모든 완성곡은 스테레오 44.1 kHz signed PCM24이며 서로 다른 해시, 실제 신호, full-scale 제외와 종료 디지털 무음을 확인했다. 사용자 원본·완성곡·프로젝트·메타데이터·검사 증거는 ignored 산출물과 요청한 로컬 전달 폴더에만 보관한다.

| 묶음 | 독립 검사 | 전달 복사 |
|---|---|---|
| 첫 8곡 | PCM 163개·패키지 160개, native 재렌더 8/8, 샘플 기여 5/5, 리믹스 정확 재합성 3/3 | 34파일·33 checksum |
| 세 파트 추가 3곡 | 190개, native 반주 3/3, 9파트 실제 기여, 모티프→레이어→마스터 정확 재합성 3/3 | 27파일·26 checksum |
| 지정 구간 추가 3곡 | 316개, native 반주 3/3, 원본 PCM·전체 모티프 재현·실제 기여 각각 13/13, 마스터 정확 재합성 3/3 | 40파일·39 checksum |

최종 합계는 완성 WAV 14개, 전달 자료 101파일, checksum 98개다. 전체 선언 파일은 재해시로 일치하며, Finder가 두 전달 폴더에 추가한 루트 `.DS_Store`만 비전달 메타데이터로 별도 기록했다. 첫 8곡의 한 전조 설명 문구는 초기 검사 뒤 바로잡고 별도 재검증했으며 음원은 바꾸지 않았다. 추가 묶음은 기존 전달 파일을 변경하지 않는다.

마지막 세 곡은 원곡의 정확한 [12,15), [88,89), [212,216)초를 모두 사용한다. 44.1 kHz에서 프레임 범위는 [529200,661500), [3880800,3924900), [9349200,9525600)이며 비트 그리드로 이동하거나 구간을 임의로 줄이지 않았다. 첫 곡의 샘플 출처는 이 세 구간으로 제한되고, 나머지 두 곡은 각각 두 구간을 추가한다. 원본 컷·가공 모티프·배치표·반주 프로젝트·재합성 도구를 함께 제공한다.

## 실패 기록과 검증 경계

처음 전체 게이트는 4820.817초로 통과했지만, 이후 수동 검사에서 Cmd+A 결함을 발견해 최종 소스로 재실행했다. 이전 설치본의 메타데이터 입력 자동화 시간 초과 두 건을 보존하며, 한 건의 포커스 상실만으로 원인을 단정하지 않는다.

첫 최종 게이트 시도는 985.879초에 새 회귀 검사의 입력 방식 가정으로 실패했다. 격리 Electron에서 page-directed `sendInputEvent`가 macOS 메뉴 accelerator를 실행하지 않음을 재현하고, 실제 메뉴 동작과 OS 단축키의 근거를 구분했다. 메뉴 누락 음성 회귀와 영어/한국어·여러 길이·실제 React 입력창 검증 후 위 최종 전체 게이트를 통과했다. 실패 로그와 source inventory를 삭제하거나 성공으로 바꾸지 않았다.

증거는 ignored `build/desktop/plan-1539-hero/` 및 장르·개인 도구 출력에 있다. 전체 증거의 최종 보존 위치는 주 checkout의 ignored `build/desktop/plan-1539-completion-evidence/`이며 원래 절대경로와 보존 경로의 대응표를 함께 남긴다. 로그의 과거 경로는 재작성하지 않는다.

이 결과는 실제 앱 동작, 파일·신호·재현성 검사다. 사람의 전곡 청취, SoundCloud 업로드·변환 결과, 외부 Developer ID 서명·공증 완료를 뜻하지 않는다.

## 공식 형식 근거

WAV 전달 형식은 [SoundCloud Upload Requirements](https://help.soundcloud.com/hc/en-us/articles/360039171614-Upload-Requirements)를 2026-09-29에 확인했다. 계정에 게시하는 작업은 수행하지 않았다.
