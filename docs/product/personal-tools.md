# 간단 화면, 내 패턴, 선택적 샘플링

화면의 **간단 / 전체 도구** 전환은 이 기기에 저장되는 표시 설정이다. 간단 화면에서는 곡 제목·템포·조성·스타일, 재생, A/B/C 패턴과 직접 편집, 편곡·믹서·내보내기에 집중한다. 보조 분석과 심화 도구는 전체 도구에서 다시 볼 수 있다. 전환해도 곡이나 Undo 기록은 바뀌지 않는다. 기존 Guided/Studio는 프로젝트 작업 방식이며 화면 정보량 설정과 독립적이다.

작곡 탭의 **내 패턴 보관함**을 열어 현재 A/B/C 중 선택한 패턴에 이름을 붙여 저장한다. 보관함은 이 기기의 앱에 남으므로 다른 프로젝트나 앱 재시작 후에도 사용할 수 있다. 불러오기는 현재 선택한 패턴만 바꾸며 Undo로 되돌릴 수 있다. 저장된 조성에 따라 음정을 현재 조성으로 맞출 수 있다. 이벤트를 재사용하는 보관함이므로 악기 소리와 샘플, 프로젝트 템포·믹서·편곡은 대상 프로젝트 설정을 따른다. 이름 변경과 삭제도 제공한다. 보관함의 로컬 저장 실패는 화면에 표시하며 성공으로 보고하지 않는다.

작곡 탭의 **샘플링 · 드럼 소리 가져오기**는 선택적 원샷 드럼 소스 기능이다. 사용자가 고른 로컬 오디오만 읽으며 킥·클랩·하이햇·퍼커션 중 한 레인의 기존 이벤트에 매핑한다. 구간과 볼륨을 조절하고 미리 듣거나 제거할 수 있다. 프로젝트에 포함된 샘플은 저장·다시 열기, 실시간 재생, WAV와 Drums stem 출력에 함께 사용된다. 샘플이 없는 프로젝트의 내장 악기 경로는 그대로 유지한다.

입력은 2 MB 이하, 0.01~2초의 모노 또는 스테레오 WAV다. 정수 PCM 8/16/24/32-bit와 32-bit float, 8~192 kHz를 지원하며 프로젝트에는 22.05 kHz 모노 PCM16으로 변환해 포함한다. 네 드럼 레인에 보관하는 원본 샘플 길이의 합은 2초 이하여야 한다. 구간을 줄여도 원본 보관 용량은 줄지 않는다.

이 기능은 긴 오디오 클립 편집, 마이크 녹음, 자동 타임 스트레치가 아니다. 가져오기 용량과 원샷 시간 제한은 패널에 표시한다. 가져온 소리는 경로 대신 파일명·출처 정보와 제한된 PCM으로 저장하며 로컬 프로젝트와 복구 데이터에 포함된다. 사용자가 사용할 권리가 있는 소스를 선택해야 한다. 테스트와 전달 음원은 직접 합성한 원본 소리만 사용한다.

SoundCloud 전달 폴더의 `00-SoundCloud-WAV`에는 업로드할 완성 믹스를 모은다. WAV는 스테레오 44.1 kHz / 24-bit PCM이며 프로젝트와 메타데이터는 별도 폴더로 분리한다. 지원 형식은 [SoundCloud Upload Requirements](https://help.soundcloud.com/hc/en-us/articles/360039171614)를 따른다. 파일 준비와 로컬 검증은 계정 업로드·게시 또는 사람의 전곡 청취를 의미하지 않는다.
